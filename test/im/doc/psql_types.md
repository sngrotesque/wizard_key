PostgreSQL 支持丰富的数据类型，涵盖基础类型、结构化类型、空间类型等，以下是主要分类及示例：

---

### **一、基本数据类型**
1. **数值类型**  
   - **整数**：  
     - `SMALLINT`（2字节，-32768~32767）  
     - `INTEGER`/`INT`（4字节，常用）  
     - `BIGINT`（8字节，大范围整数）  
     - `SERIAL`/`BIGSERIAL`（自增整数，常用于主键）  
   - **浮点数**：  
     - `REAL`（4字节，单精度）  
     - `DOUBLE PRECISION`（8字节，双精度）  
   - **精确小数**：  
     - `NUMERIC(p,s)` 或 `DECIMAL(p,s)`（高精度计算，如货币）  

2. **字符与文本类型**  
   - `CHAR(n)`：定长字符串，不足补空格（如 `CHAR(5)` 存储 `'ab'` 变为 `'ab   '`）  
   - `VARCHAR(n)`：变长字符串，最大长度 1GB  
   - `TEXT`：无限长度文本（推荐替代 `VARCHAR`）  

3. **布尔类型**  
   - `BOOLEAN`：值为 `TRUE`/`FALSE`/`NULL`（不区分大小写，如 `'t'` 或 `'1'` 视为 `TRUE`）  

4. **二进制类型**  
   - `BYTEA`：存储二进制数据（如图片、文件）  

---

### **二、日期与时间类型**
- `DATE`：仅日期（如 `'2025-08-14'`）  
- `TIME`：仅时间（如 `'14:30:00'`）  
- `TIMESTAMP`：日期+时间（无时区）  
- `TIMESTAMPTZ`：带时区的日期时间（推荐）  
- `INTERVAL`：时间间隔（如 `'1 day 2 hours'`）  

---

### **三、结构化与特殊类型**
1. **数组类型**  
   - 支持任意类型的数组，如 `INTEGER[]` 或 `TEXT[][]`，示例：  
     ```sql
     INSERT INTO table VALUES (ARRAY[1, 2, 3], '{{"a","b"},{"c","d"}}');
     ```  
       

2. **JSON 类型**  
   - `JSON`：文本存储，不验证格式  
   - `JSONB`：二进制存储（推荐，支持索引和高效查询）  

3. **UUID**  
   - 全局唯一标识符（如 `'a0eebc99-9c0b-4ef8-bb6d-6bb9bd380a11'`）  

4. **枚举与范围类型**  
   - 枚举：需通过 `CREATE TYPE` 自定义（如 `CREATE TYPE mood AS ENUM ('happy', 'sad')`）  
   - 范围：如 `int4range`（整数范围）、`tsrange`（时间戳范围）  

---

### **四、空间与网络类型**
1. **几何类型**（需 PostGIS 扩展）  
   - 点（`POINT`）、线（`LINE`）、多边形（`POLYGON`）等  

2. **网络地址类型**  
   - `INET`（IPv4/IPv6）、`CIDR`（网络地址块）、`MACADDR`（MAC地址）  

3. **全文检索类型**  
   - `TSVECTOR`（分词存储）、`TSQUERY`（查询条件）  

---

### **五、其他高级类型**
- `XML`：存储 XML 文档  
- `HSTORE`：键值对存储（需 `hstore` 扩展）  
- 自定义类型：通过 `CREATE TYPE` 定义复合类型  

---

### **总结**
PostgreSQL 的数据类型系统以灵活性和扩展性著称，支持从基础数值到复杂结构（如 JSONB、几何图形）的存储。开发者可根据业务需求选择合适类型，例如：  
- **精确计算**：用 `NUMERIC` 避免浮点误差  
- **国际化文本**：`TEXT` 配合 UTF-8 编码  
- **空间数据**：结合 PostGIS 扩展使用几何类型  

如需完整列表或具体类型的详细用法，可参考官方文档或上述来源中的示例。
